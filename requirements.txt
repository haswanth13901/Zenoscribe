# Non-pip / outside the venv
# These are NOT installable via this file — pip can't manage them. Listed
# here only so the full dependency picture lives in one place.
#
#   Node.js + npm (frontend/)
#     Powers the React/RTK /home frontend. Not a Python package at all.
#       npm --prefix frontend install
#       npm --prefix frontend run build   # or `run dev` for local dev
#
#   Playwright browser binaries
#     The `playwright` pip package above only installs the Python driver;
#     the actual browser executables are a separate download, per-machine:
#       python -m playwright install --with-deps
#
#   System libraries (Dockerfile installs these via apt-get; on bare metal
#   install the OS equivalent yourself)
#     build-essential, libssl-dev  - build toolchain for compiled deps
#     libsndfile1                 - required by `scipy`/`sounddevice` for
#                                    audio file I/O on Linux
#     portaudio                   - required by `sounddevice` for live mic
#                                    capture (e.g. `apt-get install
#                                    portaudio19-dev`); usually unnecessary
#                                    since the web app captures audio in the
#                                    browser, not via sounddevice
